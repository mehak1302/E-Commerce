# E-Commerce Web Application

A full-stack e-commerce web application built using Python and Django, featuring user authentication, product catalogs, shopping cart, and Razorpay payment gateway integration.

## 🚀 Tech Stack
* **Backend:** Python, Django
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite / MySQL
* **Payment Gateway:** Razorpay

## 📂 Project Structure
* `accounts/` - User authentication and profile management
* `products/` - Product catalog and listing
* `ecommerce/` - Main project settings and configurations
* `templates/` - HTML templates for UI
